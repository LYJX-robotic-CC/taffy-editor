# taffy 本地 3D 编辑器

面向 PCD 点云和 PLY 网格的两个独立桌面工具，使用 Qt、VTK 和塔菲主题界面，无需浏览器。启动时默认空白场景，文件仅在本机处理。

## 安装

本次两个 DEB 适用于 Ubuntu 22.04 / Python 3.10，需要图形桌面和支持 OpenGL 3.2 或更高版本的显卡驱动。安装包依赖系统 Python、PyQt5、NumPy 和 VTK；PCD 编辑器另依赖 Open3D、SciPy。

在下载目录执行所需命令（也可以同时安装）：

```bash
sudo apt install ./taffy-editor_1.3_all.deb
sudo apt install ./taffy-mesh-editor_1.1_all.deb
```

安装后从应用菜单打开，或分别运行 `taffy-editor`、`taffy-mesh-editor`。

仓库仅提供安装包、图标和使用说明，不上传项目源码。DEB 中的应用使用 Python 3.10 字节码，不含 Python 明文源码。历史 [Windows 1.2 试用包](https://github.com/LYJX-robotic-CC/taffy-editor/releases/tag/v1.2) 保留在旧发布中，本次更新的是 Linux 版。

## 共同操作

- 左侧导入文件，每个文件形成独立图层。软件各自记住最近打开的文件和目录，关闭后重开仍保留。
- 单击图层选中，双击图层同时打开可见性；每次仅编辑一个图层。眼睛按钮切换显隐。
- 图层右侧 `⋯` 菜单提供导出、保存及删除图层。删除图层只从场景移除，磁盘上的原文件保留。长文件名自动省略，悬停可看完整名称。
- 鼠标左键拖动旋转、中键拖动平移、右键拖动缩放。支持一键俯视、按住按钮绕 Z 轴旋转、网格开关和截图。
- 左侧 Z、右侧 X、底部 Y 滑块控制当前层显示范围；“重置”恢复三个轴的完整范围。各图层范围独立。

## PCD 点云编辑

支持大规模点云抽样渲染。显示抽样用于减少显存占用；滤波、删点、补全、保存和导出使用当前图层的完整编辑数据。导入时先显示抽样，完整点云加载完成后可执行编辑。

### 滤波

展开右侧“滤波”，默认关闭。支持体素降采样、统计离群点、半径离群点及自动密度参数。调参后点击“重新计算滤波”才会运行；拖动参数滑块不会自动重算。

只处理当前 XYZ 范围内的完整点云，范围外的点保持不变。成功后结果写入当前层，继续拖动显示范围不会撤销滤波；保存、导出包含整层已编辑数据。建议先导出副本再保留重要修改。

### 删除与补全

1. 选中目标层，调整 XYZ 显示范围。
2. 展开“删除与补全点云”，点击“开始选点区域”。
3. 在当前层显示范围内双击至少 4 个不同且不共面的点，拖动仍可调整相机。
4. 设置外扩厘米数，点击“计算凸包区域”。外扩作用于 XYZ 三个方向，预览与操作使用同一凸包。
5. 选择删除或补全区域点。操作只影响当前层，并限于当前 XYZ 范围；补全采用随机近似采样，点间距可调。

滤波、删除、补全和文件写入在后台运行，处理期间等待完成后再切换编辑层。大范围运算仍可能耗时或受到内存预算限制。
